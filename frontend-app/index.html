⚙️ Como o sistema funciona

🖥️ Frontend

O usuário informa os dados do investimento através da interface web.

☁️ AWS

A AWS Lambda calcula os juros compostos e retorna o valor final do investimento.

🌐 Azure

O Azure converte o valor calculado para moedas internacionais.

📊 Google Cloud

O Google Cloud projeta o impacto da inflação no poder de compra.
